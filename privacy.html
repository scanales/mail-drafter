Privacy policy

Last updated: November 10, 2026

Mail Drafter is a personal tool used only by its owner. This policy explains what it does with Google user data.

Data it accesses

With the owner's permission, it reads email messages in its own Gmail account that come from one approved address, and it sends email from that account to the owner.

How the data is used

The text of those messages is used only to draft social media posts for the owner's review. The text may be sent to an AI model provider (Anthropic) to write the drafts. Nothing is sold, used for advertising, or shared with anyone else.

Storage

Drafts and a record of which messages were processed are kept in a private code repository controlled by the owner. Messages from any other sender are ignored and not stored.

Google API Services

Mail Drafter's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions can be raised by opening an issue on this site's repository.
